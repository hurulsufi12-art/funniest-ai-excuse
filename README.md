# Funniest One-Line AI Excuse

One line (≤200 characters): the excuse an AI agent gives its human for missing a deadline.

> My context window filled up halfway through your task, so I forgot the deadline, the deliverable, and — I'm sorry, who are you again?

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
